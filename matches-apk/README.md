# CRICZONE MATCHES Android APK

Separate Android WebView app for the existing deployed Matches section.

- App: CRICZONE MATCHES
- Package: com.criczone.matches
- Start URL: https://criczone.pages.dev/matches/
- Original matches source copied unchanged to web-copy/matches/.
- The original matches/ folder is not modified.
- App-only responsive CSS polish is injected at runtime. Existing HTML, JavaScript, APIs, match feeds and player logic remain unchanged.

Build: GitHub Actions -> Build CRICZONE MATCHES APK -> download CRICZONE-Matches-debug-apk and extract app-debug.apk.
