# CRICZONE Android

Native Android application foundation for CRICZONE, built with Kotlin, Jetpack Compose and Android WebView.

## Open in Android Studio
1. Open the `android/` directory in Android Studio.
2. Use JDK 17.
3. Allow Gradle sync to complete.
4. Run the `app` configuration on an Android 6.0+ device or emulator.

## Included
- Premium dark UI with CRICZONE yellow accents
- Home, Search, Favorites and Telegram tabs
- Favorites stored locally on device
- In-app WebView iframe player with JavaScript, DOM storage and media autoplay configuration
- Fullscreen custom-view handling and landscape orientation
- HTTPS-only player page loading
- Demo channel metadata only

## Iframe player configuration
Each channel's `streamUrl` is the HTTPS CRICZONE player page that should be embedded in the iframe. It is not a raw media URL. Configure it only with a player page that CRICZONE is authorized to embed and distribute. The sample channels intentionally have no playback URL configured yet.

The current repository website endpoints are browser-origin restricted and are not a supported native-app API. Add a dedicated app API and D1-backed admin channel catalog before enabling remote channels.

Suggested API contract:
- GET /api/app/v1/channels — public metadata for published channels
- GET /api/app/v1/config — branding, Telegram URL and feature flags
- POST /api/admin/v1/channels — create/update channel metadata (admin auth)
- DELETE /api/admin/v1/channels/:id — remove a channel (admin auth)

Keep provider credentials and DRM secrets on the server; never embed them in the APK. The iframe host may also enforce its own frame-ancestors / X-Frame-Options policy, in which case it must explicitly permit embedding by the CRICZONE app player origin. Do not bypass those protections.
