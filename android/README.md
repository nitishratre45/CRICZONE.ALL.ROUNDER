# CRICZONE Android

Native Android application foundation for CRICZONE, built with Kotlin, Jetpack Compose and AndroidX Media3.

## Open in Android Studio
1. Open the `android/` directory in Android Studio.
2. Use JDK 17.
3. Allow Gradle sync to complete.
4. Run the `app` configuration on an Android 6.0+ device or emulator.

## Included
- Premium dark UI with CRICZONE yellow accents
- Home, Search, Favorites and Telegram tabs
- Favorites stored locally on device
- Media3 player foundation with HLS and DASH modules
- Playback screen with native player controls
- Demo channel metadata only

## Backend integration required
The current website channel endpoint is browser-origin restricted and is not a supported native-app API. Add a dedicated authenticated app API and D1-backed admin channel catalog before enabling remote channels.

Suggested API contract:
- GET /api/app/v1/channels — public metadata for published channels
- GET /api/app/v1/config — branding, Telegram URL and feature flags
- POST /api/admin/v1/channels — create/update channel metadata (admin auth)
- DELETE /api/admin/v1/channels/:id — remove a channel (admin auth)

A published channel record should include id, name, category, language, logoUrl and streamType. Include playback URLs only when CRICZONE has permission to distribute them. Keep provider credentials and DRM secrets on the server; never embed them in the APK.
